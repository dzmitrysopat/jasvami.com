# Дипломы и сертификаты

Списки на главной странице берутся из двух файлов:

- `diplomas.json` — «Обучающие курсы и курсы повышения квалификации», картинки лежат в `img/diplomas/`
- `conferences.json` — «Участие в профессиональных конференциях», картинки лежат в `img/conferentions/`

Чтобы добавить документ:

1. Положите изображение (jpg, png, webp, любого размера и ориентации) в нужную папку `img/…`.
2. Добавьте строку в нужный JSON-файл:

   `{"file": "имя_файла.webp", "title": "Подпись под изображением"}`

   Порядок строк = порядок на сайте (новые сверху). Между строками нужна запятая, после последней строки запятой быть не должно, кавычки только прямые `"`.
3. Загрузите файлы на хостинг. Ничего подгонять не нужно: миниатюры и полноэкранный просмотр подстраиваются сами.

Если JSON написан с ошибкой или файла картинки нет, ошибка видна в консоли браузера (F12), а отсутствующие картинки просто не показываются.
